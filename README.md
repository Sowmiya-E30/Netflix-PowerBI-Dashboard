# Netflix Content Analytics Dashboard

## Overview
An interactive Power BI dashboard created to analyze Netflix content based on content type, ratings, genres, release year, duration, and country.

## Tools & Technologies
- Power BI
- DAX
- Data Cleaning
- Data Visualization
- CSV Dataset

## Dashboard Features
- Total Shows
- Total Ratings
- Total Genres
- Total Directors
- Average Movie Duration
- Movies vs TV Shows
- Ratings Analysis
- Genre Analysis
- Release Year Trends
- Country-wise Distribution

## DAX
Created calculated columns and measures using DAX, including:
- Distinct counts
- Average movie duration in minutes

## Dataset
Netflix Titles dataset containing information about movies and TV shows available on Netflix.
